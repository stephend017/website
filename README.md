# Personal Website Starter

This repository is scaffolded with:
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- MDX-ready page extensions

## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Current routes
- `/` Home
- `/about` About
- `/projects` Projects
