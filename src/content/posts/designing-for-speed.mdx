# Designing for Speed

Speed is mostly about reducing friction in the moments users repeat.

## Practical rules

1. Make high-frequency actions obvious.
2. Keep visual hierarchy stable across pages.
3. Remove decorative work that delays interaction.

Small cuts to complexity usually outperform large one-time redesigns.
